# NativeEar 🎧 - TOEIC 英語リスニング・ディクテーションWebアプリ

TOEICリスニングスコアアップ（500〜900点）を目指すための高機能ディクテーションWebアプリケーションです。

---

## 🌟 主な機能と特徴

1. **TOEIC 5段階レベル別学習**
   - **500点クラス**: 基礎短文・クリア発音（基本速度: 0.88x）
   - **600点クラス**: 日常業務・標準スピード（基本速度: 0.98x）
   - **700点クラス**: 実務討議・重要イディオム（基本速度: 1.02x）
   - **800点クラス**: 高度ビジネス・複文構造（基本速度: 1.10x）
   - **900点クラス**: ネイティブ最速・リダクション・難関語彙（基本速度: 1.18x）

2. **Web Speech API ネイティブ発音 & 音声切替**
   - 米国英語（en-US）の女性ネイティブ（Female）/ 男性ネイティブ（Male）音声を瞬時に切替可能
   - レベル別自動推奨速度 ＋ 速度微調整（0.75x, 0.88x, 1.0x, 1.1x, 1.25x）
   - Web Audio API によるシンセサイザー効果音（正解時アルペジオファンファーレなど）

3. **リアルタイム Word-by-Word Diff 判定エンジン**
   - 🟩 正解単語（Match）
   - 🟥 誤り・スペルミス単語（Mismatch: `入力` → `模範解答`）
   - 🟨 脱落単語（Missing: `[単語]`）
   - 🟦 余剰単語（Extra: `~~単語~~`）
   - 句読点（ピリオド・カンマ等）や大文字小文字の柔軟な正規化（設定で厳格モードへの切替も可能）

4. **学習サポート・解説**
   - 日本語全訳
   - 重要ビジネス語彙・イディオム解説
   - TOEICリスニングの文法ポイント・解法Tips
   - ネイティブ特有の音の連結（リンキング / リダクション）解説

5. **学習履歴 & 苦手復習システム**
   - 苦手問題のワンクリックブックマーク＆専用復習モード
   - レベル別正答率・平均一致率・完全正解数・連続日数（Streak）トラッキング
   - `localStorage` による完全永続化

6. **洗練されたレスポンシブUI & ショートカット**
   - PC / スマートフォン対応
   - ダークモード / ライトモード対応
   - キーボードショートカット:
     - `Space` / `Ctrl+P`: 音声再生・もう一度聴く
     - `Enter`: 判定 / 次の問題へ進む
     - `Tab`: 次の問題へ

## 🚀 起動方法

```bash
# 開発サーバー起動
npm run dev

# プロダクションビルド
npm run build

# プレビュー
npm run preview
```

## 🛠 技術スタック
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons, Canvas Confetti
- **Audio Engine**: Web Speech API (`SpeechSynthesis`) + Web Audio API (`AudioContext`)
- **Algorithms**: Dynamic Programming LCS Word Alignment Token Diff
